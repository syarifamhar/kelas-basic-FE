// NIGHT SHIFT · v1.0

A design system for late-night tinkerers.

It feels like your favorite code editor at 2am: deep, low-glare surfaces, soft neon used only where it means something, and monospace wherever a machine is talking.

01 calm by default
Neutrals do 90% of the work. Neon is a signal, not decoration.
02 mono for machines
Labels, values and code use mono. Humans get Plex Sans.
03 snap to 4
Every space, size and radius is a multiple of 4.
